# Full Mesh Labs downloads

Release files for the Full Mesh Labs app and its free lab lessons.

**Start at [fullmeshlabs.com](https://fullmeshlabs.com).** The site's download buttons hand out the files kept here, with setup steps and the list of labs. You do not need to pick anything from this page.

## What is here

- **The app, for Windows 11.** Each release named `v<version>` holds one zip. It is a beta: an early version that is still changing. The app looks for a newer version when it opens and asks before it installs one.
- **Lessons** (`.labpack` files). Open them with the app.

Every file's size and SHA-256 are shown on the site beside its download.

This repository holds release files only. It has no source code.
